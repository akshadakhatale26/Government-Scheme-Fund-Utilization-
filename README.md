# Government-Scheme-Fund-Utilization-
## 📌 Project Overview

This project analyzes a **synthetic Government Scheme Fund Utilization dataset** containing 1,000 artificially generated records and 21 features. The project focuses on exploring fund allocation, fund releases, utilization, physical target achievement, and beneficiary coverage using Python,Power Query, and Power BI.

**Disclaimer:** This dataset is synthetic and does not represent actual government records, financial transactions, beneficiary data, or real-world scheme performance. All findings are for educational and portfolio demonstration purposes only.

## 🎯 Project Objectives

- Analyze sanctioned, released, and utilized funds.
- Identify fund utilization patterns and unutilized amounts.
- Compare fund distribution across states, departments, schemes, and financial years.
- Analyze physical targets versus physical target achievement.
- Evaluate beneficiary targets and coverage.
- Explore relationships between financial and performance indicators.
- Build an interactive Power BI dashboard to present key insights.

## 🛠️ Tools and Technologies

- **Python:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **ETL:** Power Query
- **Business Intelligence:** Power BI
- **Data Modeling:** Fact and dimension tables, Star Schema
- **Power BI Features:** DAX measures, KPI cards, slicers, bookmarks, buttons, and interactive visualizations

## 🔍 Work Completed

### 1. Python – Data Cleaning and Exploratory Data Analysis (EDA)

- Inspected dataset structure, column names, data types, and summary statistics.
- Identified missing values and examined data quality issues.
- Explored numerical variables using descriptive statistics.
- Analyzed fund allocation, fund releases, fund utilization, and beneficiary coverage.
- Compared state-wise, department-wise, scheme-wise, and financial-year-wise metrics.
- Examined physical target and physical achievement indicators.
- Investigated relationships between numerical variables through correlation analysis.
- Used boxplots to examine distributions, spread, and potential outliers.

### 2. Data Visualization Using Python

Created visualizations using Matplotlib and Seaborn to explore:

- Distributions of financial and performance indicators.
- Outliers in fund-related numerical columns using boxplots.
- Correlations between sanctioned funds, released funds, utilized funds, beneficiaries, and physical achievement.
- Patterns and relationships within the dataset through exploratory charts.

### 3. ETL Using Power Query

- Imported the dataset into Power Query.
- Inspected and corrected data types.
- Performed data cleaning and transformation.
- Handled missing values and reviewed data quality.
- Prepared the dataset for analysis and reporting.
- Organized the data into fact and dimension tables for structured modeling.

### 4. Data Modeling in Power BI

- Designed a Star Schema using fact and dimension tables.
- Created relationships between the fact table and dimension tables.
- Prepared the model for cross-filtering and interactive analysis.
- Used the model to analyze data across financial years, states, departments, and schemes.

### 5. Power BI Dashboard Development

Developed an interactive dashboard to present key fund utilization and scheme performance indicators.

**Dashboard features include:**

- KPI cards for key financial indicators.
- Fund released and fund utilized comparisons.
- State-wise and department-wise analysis.
- Scheme-wise performance analysis.
- Financial-year-wise trend analysis.
- Physical target and achievement analysis.
- Beneficiary coverage analysis.
- Interactive slicers and filters.
- Multiple visualizations for comparing financial and operational indicators.
- Buttons and bookmarks for dashboard navigation and interactive report experiences.
