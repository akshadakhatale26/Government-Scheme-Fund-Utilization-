# Government-Scheme-Fund-Utilization-
📌 Project Overview

This project focuses on analyzing a synthetic Government Scheme Fund Utilization Dataset (India) containing 1,000 artificially generated records and 21 features. The dataset represents hypothetical government scheme funding, fund releases, expenditure, physical targets, beneficiary coverage, implementation status, and audit information.

The objective is to perform data cleaning, Exploratory Data Analysis (EDA), financial analysis, and data visualization to identify patterns, compare funding and utilization, and evaluate physical target achievement and beneficiary coverage.

⚠️ Dataset Disclaimer

This project uses a synthetic dataset created for educational, demonstration, portfolio, and data-analytics practice purposes.
Although the scheme names, departments, launch years, and funding-pattern classifications are based on publicly known Indian government schemes, the financial amounts, beneficiary counts, districts, officer information, audit remarks, and individual records are artificially generated.
The dataset does not represent actual government fund flows, expenditure, beneficiaries, or the performance of real government schemes. The results must not be interpreted as official government statistics or used for policy, financial, or other real-world decisions.

🎯 Project Objectives

Analyze sanctioned, released, and utilized funds across government schemes.
Calculate fund utilization percentages and identify unutilized fund gaps.
Compare financial performance across states, departments, schemes, and financial years.
Evaluate physical targets against actual recorded achievements.
Analyze beneficiary targets and coverage.
Explore relationships between financial indicators and implementation outcomes.
Develop interactive dashboards to communicate findings effectively.

🛠️ Tools and Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn
Power BI: Data modeling, DAX measures, KPI cards, and interactive dashboards
Power Query: Data cleaning and transformation

📊 Analysis Performed

Data cleaning and missing-value handling
Exploratory Data Analysis (EDA)
Statistical summaries and correlation analysis
Fund allocation, release, and utilization analysis
State-wise, department-wise, scheme-wise, and financial-year comparisons
Physical target versus achievement analysis
Beneficiary coverage analysis
Data visualization and dashboard development

📈 Expected Outcomes

This project demonstrates how data analytics techniques can be used to explore funding patterns, identify recorded utilization gaps, compare performance indicators, and present findings through visualizations and interactive dashboards.

👩‍💻 Project Purpose

This project demonstrates practical skills in data cleaning, SQL analysis, Python-based EDA, financial analytics, data modeling, and Power BI dashboard development.
